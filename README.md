# Workout Planner 💪

A web application that generates personalized workout plans tailored to your fitness goals, experience level, and preferences. Powered by AI, this application creates customized training programs based on your specific needs and constraints.

## 🎯 Features

- **Personalized Workout Plans**: Generate AI-powered customized workout plans based on your profile
- **User Onboarding**: Easy-to-use onboarding flow to capture your fitness preferences
- **Flexible Configuration**:
  - Multiple fitness goals (strength, hypertrophy, endurance, etc.)
  - Experience levels (beginner, intermediate, advanced)
  - Customizable workout frequency (days per week)
  - Session duration preferences
  - Equipment availability
  - Injury management and limitations
  - Preferred workout splits (PPL, Upper/Lower, Full Body, etc.)
- **PDF Export**: Download your workout plans as PDF documents
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## 🛠️ Tech Stack

### Frontend

- **Next.js 16** - React framework with server-side rendering and API routes

- **TypeScript** - Type-safe development
- **Tailwind CSS 4** - Utility-first CSS framework
- **Lucide React** - Beautiful icon library

### Backend

- **Next.js API Routes** - Serverless backend functions
- **OpenAI API** - AI-powered workout plan generation

### Database
